# 🐶 Dog Breed Classification System

A Deep Learning based web application to classify dog breeds from images.

---

## 📌 Project Overview

This project uses a **Convolutional Neural Network (CNN)** model trained on ImageNet 
to identify **200+ dog breeds**.

Built using:
- TensorFlow
- Streamlit
- Python

---

## 🚀 Features

✅ Upload dog image  
✅ Predict breed  
✅ Confidence score  
✅ Top 5 predictions graph  
✅ Clean website UI  
✅ Dog care section  

---

## 🛠 Tech Stack

- Python 3.10
- TensorFlow / Keras
- Streamlit
- NumPy
- Pandas
- Matplotlib
